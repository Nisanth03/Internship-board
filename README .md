# Responsive Internship Board

A beginner-friendly responsive internship listing website built without a frontend framework.

## Features

- Search internships by title, skill, domain, work mode or location
- Filter internships by domain
- Filter internships by work mode
- View internship details
- Internship application form
- Form validation
- Loading state
- Empty search results state
- Error and retry state
- Keyboard-friendly navigation
- Responsive layout for mobile, tablet and desktop

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- index.html - Main page structure
- style.css - Responsive styling
- script.js - Search, filters, details and application functionality
- data.js - Internship records
- README.md - Project documentation

## Responsive Testing

The project was tested at:

- 360px mobile width
- 768px tablet width
- Desktop width

The layout, search, filters, internship cards, details dialog and application form were checked at these sizes.

## How to Run

Open `index.html` in a web browser.

No framework or installation is required.
